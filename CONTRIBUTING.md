# Contributing

Thank you for helping make DataConnect integrations easier to adopt.

## Before opening a pull request

1. Open an issue for substantial new behavior.
2. Do not include credentials, JWTs, real customer data, generated output, or
   material copied from confidential documentation.
3. Add or update the relevant example README.
4. Add tests and run the language's documented quality commands.
5. Run examples in `--dry-run` mode. Live calls are optional for contributors.

New user-facing scenarios must maintain Python, Java, and .NET parity unless a
maintainer approves a staged change and creates follow-up issues. A
language-specific bug fix does not need unrelated ports.

By submitting a contribution, you agree that it is licensed under Apache-2.0.
