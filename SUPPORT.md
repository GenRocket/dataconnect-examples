# Support

- Use GitHub Discussions for setup questions and implementation ideas.
- Use GitHub Issues for reproducible defects in this repository.
- Use GenRocket's customer support channel for account enablement, quota,
  production endpoints, or service incidents.
- Use private vulnerability reporting for security concerns.

Include the language/runtime, protocol, example name, sanitized error code, and
reproduction command. Never include an API key, JWT, or `.env` file.
