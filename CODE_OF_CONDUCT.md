# Code of conduct

This project follows the [Contributor Covenant Code of Conduct, version
2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

We pledge to make participation a harassment-free experience for everyone.
Examples of unacceptable behavior include harassment, trolling, derogatory
comments, publishing another person's private information, or other conduct
reasonably considered inappropriate in a professional setting.

Maintainers may remove or reject contributions that do not align with this
code. Report enforcement matters privately through the repository's security
reporting flow.
